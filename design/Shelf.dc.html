The Shelf

Workspaces become tabs down the outer edge, like files standing in a drawer — names running up the spine, each in its own colour. The tab you are on joins the panel: the seam between them disappears, so the open workspace and its contents are visibly one object and every other one is visibly behind it.

The structural change: switching moves to the screen edge — the easiest target a pointer can hit, since you cannot overshoot it. The panel then carries nothing but the current workspace, so it needs no header telling you where you are; the joined tab already said it.

The joined seam
The active tab is the same white as the panel and overlaps it by 9px, so there is no line between them. That one detail is what makes it read as a file pulled forward rather than a button that happens to be lit.
Fitts’s law, for free
Tabs sit against the window edge, so the pointer cannot overshoot them — you can throw the mouse left and land every time. The same trick the Mac menu bar uses.
The risk
Sideways names are slower to read, and the drawer only holds five or six before it needs scrolling. Best if you keep a handful of spaces; wrong if you keep twenty.
